# シャドトレ（PWA版）使い方メモ

## このフォルダの中身
| ファイル | 役割 |
|---|---|
| index.html | アプリ本体の画面 |
| css/app.css, js/app.js, js/materials.js | 見た目・動き・収録教材（Part 1〜4） |
| manifest.json | ホーム画面に入れたときの名前・色・アイコンの設定 |
| sw.js | オフラインでも起動できるようにする仕組み（Service Worker） |
| icon-192.png / icon-512.png / icon-maskable-512.png / apple-touch-icon.png | アイコン |
| vendor/tesseract/ | 画像から英文を読み取る無料OCR（端末内で動く、約11MB） |
| _headers / vercel.json | 公開先サーバー用の小さな設定（触らなくてOK） |

## 1. ネットに無料で公開する（Netlify Drop）
1. https://app.netlify.com/drop を開く（無料アカウントを作ってログインしておく。ログインなしだと1時間で消える）
2. この **shadotore フォルダごと** 画面にドラッグ＆ドロップ
3. 数十秒で `https://〇〇〇.netlify.app` のURLが出る → これがアプリのURL
4. 名前を変えたいときは「Site configuration → Change site name」
5. 更新するときは「Deploys」画面に新しいフォルダを再度ドロップ

※ スマホだけでは難しいので、最初の公開はパソコンで行う。
※ Vercel でも公開できる（GitHubにフォルダを上げて vercel.com で読み込む）。ただし `vercel.app` は中国本土からつながりにくいと言われているので、上海で使うなら Netlify を優先。

## 2. ホーム画面に追加する
### iPhone（Safari）
1. Safari で公開URLを開く（Chromeアプリ等ではなくSafari）
2. 共有ボタン（□に↑）をタップ ※iOS 26 は右下「…」→「共有」
3. 「ホーム画面に追加」→ 名前が「シャドトレ」になっているのを確認 →「追加」
4. ホーム画面のアイコンから起動すると、アドレスバーなしの全画面で開く

### Android（Chrome）
1. Chrome で公開URLを開く
2. 右上「⋮」→「ホーム画面に追加」または「アプリをインストール」→「インストール」
3. アプリ一覧／ホーム画面にアイコンが出る

## 3. 知っておくこと
- **データの保存場所**：教材・WPM履歴・設定はその端末のブラウザ内に保存。iPhoneは「Safariで開いたとき」と「ホーム画面から開いたとき」で保存場所が別なので、**ホーム画面に追加してから**教材を追加する。機種変更や移行は 設定 →「バックアップ保存／読込」で。
- **APIキー**：設定画面で入れたキーはその端末のブラウザ内だけに保存され、OpenAI / Google / ElevenLabs に直接送られる。共有端末では入れない。不要になったら「キーを全部消す」。
- **中国本土から**：OpenAI・Gemini・ElevenLabs のAPIはVPNなしでは基本つながらない。つながらないときは自動で標準ブラウザ音声・端末内OCRに切り替わる。
- **訛りの再現**：タイ・ベトナム・インドネシア訛りは、AI音声に「この訛りで話して」と指示して作る。かなり近づくが本物の話者と同じにはならない。標準ブラウザ音声では「雰囲気」程度（端末にタイ語・ベトナム語・インドネシア語の音声が入っていればそれを使う）。
- **AI音声の料金**：一度作った文の音声は端末に保存するので、同じ文の2回目以降は無料・オフラインで再生できる。
- **アプリを更新したとき**：sw.js の `VERSION` を上げてから再アップロードすると、次回起動時に新しい版に切り替わる。
